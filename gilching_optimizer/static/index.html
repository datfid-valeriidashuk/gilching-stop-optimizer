Gilching Stop Optimizer

Walking distances use the OpenStreetMap pedestrian network (OSMnx), not Google Maps.

Five Gilching stops are already on the map. Add new stops from there, or load a coordinate file. Drag to move, right-click to remove.

A text file replaces the stops on the map. One stop per line, with a dot as the decimal separator: 48.11755, 11.29118. A name can come first.

Coordinates of works, one site per line. A name can come first. These sites are drawn on the map and are not used as bus stops.

A text table with name, latitude, longitude, and number of people. Save an Excel sheet as CSV. Example places are a stand-in for schools, retirement homes, and shops.

Coordinates of plots the municipality owns, or does not own. Mark each line owned or not owned. A PDF is recorded by name only. Example plots are a stand-in.

Homes stay in the model. Schools add destination demand (a pupil is a home-to-stop trip and a school-to-stop trip). The music school uses a daily-visit estimate, not full-day enrollment.

Scenario assumptions

Illustrative defaults, not measured Gilching rates. Journey and CO₂e figures use the walking network even when the map is on the wheelchair tab.
